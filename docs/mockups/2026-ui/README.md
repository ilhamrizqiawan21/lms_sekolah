## Keputusan UI yang sudah disepakati

- Produk bersifat umum; warna dasar default Indigo dan warna pilihan sekolah tetap dapat diatur.
- Pada CRUD Kelas & Siswa, form tambah siswa langsung terlihat tanpa perlu menekan tombol tambah. Tautan unduh template Excel tampil jelas di dekat aksi Import Excel.
- Aksi edit menggunakan ikon hijau dan hapus menggunakan ikon merah.
- Tampilan harus tetap terbaca dan tidak melebar pada layar ponsel.
- Isi mockup adalah contoh. Implementasi harus memakai data aplikasi yang sesungguhnya.
